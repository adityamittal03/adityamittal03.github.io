# My website

[Maverick](https://github.com/canhtran/maverick) ([license](licenses/maverick.txt)).

[GLIDE](https://arxiv.org/abs/2609.24996),
[TowerDebias](https://arxiv.org/abs/2411.08297), and
[dsld](https://arxiv.org/abs/2411.04228).

[CRAFT](https://craft-hand.github.io/),
[Open-TeleVision](https://robot-tv.github.io/), and
[π₀.₅](https://arxiv.org/abs/2504.16054) projects; citations are in the post.
